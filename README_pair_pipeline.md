# 쌍 기반 활성 차이 예측 (`ac_pipeline.ipynb`)

구조가 비슷한 두 분자 A, B를 한 번에 넣어 **활성 차이 Δ = p(B) − p(A)** 를 예측한다.
특히 구조는 거의 같은데 활성이 크게 다른 쌍(**activity cliff**, |Δ| ≥ 1 = 10배 이상 차이)을 잘 맞히는 것이 목표다.

## 1. 데이터와 쌍

- **데이터:** MoleculeACE 30개 타깃 (Ki 23개, EC50 7개), 분자 48,714개 (서로 다른 분자 35,633개)
- **분자 나누기:** 학습 64% · 검증 16% · 평가 20% (MoleculeACE 분할 + 학습 분자의 20%를 검증으로)
- **쌍 만들기:** 같은 타깃 안에서 지문 유사도(ECFP4 Tanimoto)가 0.5 이상인 두 분자를 쌍으로 만든다
  - **학습: 유사 쌍 전부** — 유사도 조건만 만족하면 전부 (여러 군데 바뀐 쌍 포함)
  - **평가: 한 군데만 다른 쌍** — 공통 구조(MCS)를 뺀 바뀐 부분이 한 덩어리이고 10원자 이하인 쌍.
    실제로 비교하는 후보 분자는 보통 한 군데만 다르기 때문이다. 유사 쌍 전부 평가도 참고로 둔다
- **평가 원칙:** 모든 쌍에 **실측값을 아는 학습 분자가 하나 이상** 들어가게 한다.
  두 분자 모두 처음 보는 쌍을 Δ만으로 평가하면, 두 분자의 활성을 똑같이 틀려도(실제 3, 0을 13, 10으로) 정답 처리되기 때문이다

## 2. 모델

![모델 구조](model_architecture.png)

- 두 분자를 **두 번 읽는다** — 분자 전체(분자 인코더)와 바뀐 부분만(조각 인코더)
- 읽은 결과에 편집 정보(무엇이 몇 군데 바뀌었는지)와 타깃을 붙여 Δ를 바로 예측한다
- 인코더는 두 가지를 비교한다
  - **GINE:** 그래프 신경망(3층, 폭 64), 처음부터 학습
  - **Mole-BERT:** 200만 분자로 미리 학습된 그래프 신경망(5층, 폭 300)을 가져와 미세조정
- **비교 대상:** 항상 0으로 답하기 / SVR(분자 지문 + 서포트 벡터 회귀, 분자별 예측 후 빼기) /
  같은 인코더로 분자별 예측 후 빼기(쌍 입력이 정말 도움이 되는지 보기 위해)
- 같은 설정을 시드 3개로 학습하고, 세 모델의 예측을 평균한 **시드 앙상블**도 함께 본다

## 3. 지금까지 결과

평가 쌍마다 **아는 분자(A) 실측 + 예측 Δ → 예측 B** 를 만들어 **B 실측과 비교한 RMSE** (낮을수록 좋음). bal = (cliff + non-cliff) / 2.

| | 한 군데만 다른 평가 쌍<br>cliff / non-cliff / bal | 참고: 유사 쌍 전부 평가<br>cliff / non-cliff / bal |
|---|---|---|
| 항상 0 | 1.717 / 0.466 / 1.091 | 1.796 / 0.490 / 1.143 |
| **SVR** | 0.928 / **0.449** / **0.688** | 0.872 / **0.459** / 0.665 |
| GINE 분자별 | 1.378 / 0.564 / 0.971 | 1.338 / 0.589 / 0.964 |
| Mole-BERT 분자별 | 1.219 / 0.570 / 0.894 | 1.160 / 0.582 / 0.871 |
| GINE 쌍 (앙상블) | 1.059 / 0.456 / 0.758 | 0.995 / 0.466 / 0.731 |
| **Mole-BERT 쌍 (앙상블)** | **0.893** / 0.491 / 0.692 | **0.832** / 0.489 / **0.660** |

(30개 타깃, 시드 3개. 쌍 모델은 유사 쌍 전부 349,565쌍으로 학습. 평가 쌍: 한 군데만 다른 쌍 43,896개, 유사 쌍 전부 218,655개)

- **Mole-BERT 쌍은 cliff에서 SVR보다 낮다** (0.893 vs 0.928). bal은 SVR과 비슷하다 (0.692 vs 0.688)
- **유사 쌍 전부로 학습한 것이 컸다.** 한 군데만 다른 쌍으로만 학습했을 때는 Mole-BERT cliff가 1.061이었다
- **non-cliff(차이가 작은 쌍)는 아직 SVR이 가장 낫다**
- **쌍으로 넣는 것이 분자별 예측보다 낫다.** 같은 인코더로 비교하면 모든 칸에서 쌍 모델이 이긴다
- **Δ만 맞히는 것은 아니다.** 학습 분자의 실측값에 Δ̂를 더해 평가 분자의 활성을 추정해도 분자별 예측보다 잘 맞힌다(다만 SVR보다는 못하다)
- **주의:** 30개 타깃을 모델 하나로 학습해서, 평가 분자의 1/3은 다른 타깃의 학습 데이터로 이미 본 분자다.
  처음 보는 분자만 보면 Mole-BERT와 SVR은 cliff에서 대등하다 (0.919 vs 0.918, 이 문제는 팀에서 논의 중)

## 4. 개선 시도 결과 (`develop.md`)

목표는 **"차이가 작은 쌍도, 큰 쌍(cliff)도 잘 맞히는 모델"** 이다. 모두 시드 3개로 쟀다.
**차이 없음** = 차이가 시드 흔들림(시드 3개의 최대−최소) 안. 숫자는 평가 쌍 bal (자세한 표는 노트북 11번 끝 "기록").

| 시도 | 결과 | 처리 |
|---|---|---|
| 학습은 유사 쌍 전부, 평가는 한 군데만 다른 쌍 | Mole-BERT 0.778 → 0.715 (흔들림 0.004, **좋아짐**), GINE 0.823 → 0.801 (흔들림 0.026, 차이 없음) | **반영** |
| 쌍 판정 고치기 (여러 군데 바뀐 쌍도 바뀐 부분 정보를 살림) | 0.777 → 0.775 (차이 없음) | 반영 — 학습 쌍 대부분이 조각 정보 없이 학습되던 문제라서 |
| 바뀐 부분 따로 읽기 (조각 인코더) | 빼면 0.823 → 0.844 (흔들림 0.060, 차이 없음) | 유지 |
| 차이가 큰 쌍에 가중치 (α) | α = 0보다 나은 경우 없음 | **뺌** |
| cliff 먼저 판단 후 예측 줄이기 (게이트) | 0.823 → 0.875–0.914 (**나빠짐**, cliff 오차 증가) | **뺌** |

### 나중에 할 일

- **손실을 평가 기준(bal)에 맞추기:** 지금 손실은 모든 쌍을 같은 무게로 봐서 쌍 수가 많은 non-cliff(약 72%)에 치우친다.
  cliff와 non-cliff가 반반 되게 무게를 주고, 학습 멈추는 기준도 bal로 (재학습 필요)
- **편집 정보만 뺀 조건 측정** (유사 쌍 전부로 학습, 재학습 필요)
- **큰 조각 처리 옵션 빼기:** 바뀐 원자가 많은 쌍의 조각 정보를 비우는 옵션. 효과 없음

## 6. 실행

```bash
CUDA_VISIBLE_DEVICES=0 jupyter nbconvert --to notebook --execute --inplace \
    --ExecutePreprocessor.timeout=-1 ac_pipeline.ipynb
```

- `data/`와 `runs/`는 올리지 않는다. 쌍 목록, 학습된 가중치, 예측값을 여기에 저장해 두고, 있으면 다시 계산하지 않는다

- Mole-BERT 가중치는 `runs/pretrained/Mole-BERT.pth`에 둔다 ([github.com/junxia97/Mole-BERT](https://github.com/junxia97/Mole-BERT))
