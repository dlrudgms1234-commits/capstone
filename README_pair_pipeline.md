# 쌍 기반 ΔpKi 예측 파이프라인 (`ac_pipeline.ipynb`)

한 곳만 다른 분자쌍 (A, B)를 입력받아 **Δ = p(B) − p(A)** 를 직접 예측한다.
3D CNN 인코더가 준비되기 전까지 인코더 자리는 GNN으로 채워두고, 그 앞뒤(입력 · 손실 · 평가 · 설명)를 먼저 완성하는 것이 목표다.

## 노트북 구성
| 섹션 | 내용 |
|---|---|
| 1–2 | MoleculeACE 30개 타깃 내려받기, 분자 단위 train/val/test split |
| 3–4 | "한 곳만 다른 쌍" 판정(ECFP4 Tanimoto ≥ 0.5 → MCS 밖 = 바뀐 부분)과 쌍 생성 |
| 4-1 | **유사 쌍 전부** — Tanimoto ≥ 0.5이면 전부 쓰는 두 번째 설정 (학습·평가 모두) |
| 5–6 | 쌍 통계와 시각화, easy/hard 기준 |
| 7 | 비교 대상: ECFP4 + SVR (분자별 예측 후 차이), "항상 0" |
| 8–9 | 그래프 입력, GINE 쌍 모델(구조·인코더·이어 붙이기·손실 그림), 가중 손실 학습, **분자별 GNN 비교군** |
| 10 | **Mole-BERT 학습** — 사전학습 인코더(GIN 5층 · 폭 300)로 분자·조각 인코더 교체 |
| 11 | 결과 비교 — 모든 비교군(항상 0, SVR, GNN 분자별, GINE 쌍, Mole-BERT 쌍, 각 시드 앙상블)을 같은 표·그림에, 기준 분자 평가, 누수 점검 |
| 12 | 결과 정리 |

## 모델 구조

![모델 구조](model_architecture.png)

- 두 분자를 **두 번 읽는다** — 한 번은 분자 전체, 한 번은 바뀐 부분만
- 읽은 결과와 편집 종류, 타깃을 이어 붙여 약효 차이를 바로 말한다
- 파란 칸(분자 전체를 읽는 부분)이 나중에 3D 입력으로 바뀔 자리다

## AC-aware 적용 지점
| 아이디어 | 구현 |
|---|---|
| ① 표현 | 바뀐 원자(MCS 밖)를 별도 인코더로, 편집 종류(replace/insert/delete/multi) one-hot |
| ② 손실 | `w = 1 + α·\|Δ\|`, 배치별 `Σw` 정규화. α는 validation cliff RMSE로 선택 |
| ③ 설명 | 원자별 기여도 → 편집 부위 비율 (미구현) |
| ④ 평가 | {train, easy, hard} × {cliff, non-cliff} RMSE + \|Δ\| 구간별 MAE |

## 실행
```bash
CUDA_VISIBLE_DEVICES=0 jupyter nbconvert --to notebook --execute --inplace \
    --ExecutePreprocessor.timeout=-1 ac_pipeline.ipynb
```
- 환경: `aienv` (rdkit, torch, torch_geometric, scikit-learn)
- `data/`와 `runs/`는 커밋하지 않는다. 노트북이 데이터를 내려받고 쌍을 다시 만든다
- 쌍 목록은 `data/pairs/`에 캐시된다 (MCS 계산이 오래 걸린다).
  판정 기준(`SIM_MIN`, `MAX_CHANGED` 등)을 바꾸면 `data/pairs/`를 지운다
- 가중치와 학습 기록은 `runs/`에 저장되고, 있으면 다시 학습하지 않는다
  - 쌍 모델: `gnn_a{α}_{TAG}_seed{seed}.pt` + `hist_...csv` (설정 2 × α 5 × 시드 3 = 30개)
  - 분자별 GNN: `gnnmol_{TAG}_ep1000_seed{seed}.pt` + `histmol_...csv` (시드 3개)
- **예측값도 `runs/preds_*.pkl`에 저장**된다. 있으면 예측을 건너뛰어, 그림·표만 고칠 때 전체 실행이 수 분이면 끝난다.
  파일 이름에 가중치 수정 시각이 들어가므로 다시 학습하면 자동으로 새로 예측한다
- 처음부터 실행하면 쌍 생성 + 학습 + 예측에 수 시간, 가중치만 있으면 약 1시간, 예측값까지 있으면 수 분
- 진행 상황은 `runs/train.log`에 남는다 (노트북 출력은 실행이 끝나야 저장되므로)

## 현재 상태 (2026-10-06, MoleculeACE 30개 타깃 전체)

### 평가 방식 — 기준 분자가 있는 쌍만

두 분자 모두 처음 보는 쌍(hard)을 Δ만으로 평가하면, 두 분자의 활성을 **똑같이 틀려도** 정답 처리된다.
그래서 **모든 쌍이 학습 분자(실측값을 아는 분자)를 하나 이상 포함**하도록 했고,
**기준 분자 평가**(평가 분자 활성 = 학습 분자 실측값 + Δ̂, 기준이 여러 개면 평균)를 추가했다.
SQRL(Zadorozhny et al., 2024)도 같은 방식으로 추론한다.

### 사전학습 인코더 — Mole-BERT

GINE(폭 64, 3층, 처음부터 학습) 자리를 **Mole-BERT**(Xia et al., ICLR 2023; ZINC 200만 분자 자기지도 사전학습, GIN 5층 · 폭 300)로 바꿨다.
인코더는 학습률 1e-4로 미세조정, 이어 붙이기·헤드·손실·평가는 그대로다.

### Δ 예측 (평가 쌍, 시드 3개 평균 · 앙상블 = 같은 α의 시드 3개 예측 평균)

| | 한 군데만: cliff | 한 군데만: non-cliff | 유사 쌍 전부: cliff | 유사 쌍 전부: non-cliff |
|---|---|---|---|---|
| 항상 0 | 1.720 | 0.465 | 1.796 | 0.490 |
| SVR | **0.928** | **0.447** | 0.872 | **0.459** |
| GNN 분자별 | 1.379 | 0.563 | 1.338 | 0.589 |
| GINE 쌍 α=0 앙상블 | 1.119 | 0.460 | 0.986 | 0.472 |
| Mole-BERT 쌍 α=0 앙상블 | 1.049 | 0.472 | 0.839 | 0.491 |
| Mole-BERT 쌍 α=1 앙상블 | — | — | **0.825** | 0.509 |

### 개별 활성 추정 (기준 분자 평가, 앙상블)

| | 한 군데만 | 유사 쌍 전부 | 기준별 흩어짐 (유사 쌍 전부) |
|---|---|---|---|
| SVR · 바로 | **0.625** | **0.661** | — (SVR 기준 분자 0.10) |
| GINE 쌍 α=0 | 0.661 | 0.679 | 0.37 |
| Mole-BERT 쌍 α=0 | 0.672 | 0.705 | **0.16** |

### 알게 된 것
1. **Mole-BERT가 유사 쌍 전부에서 cliff로 SVR을 처음 넘었다** (0.825 vs 0.872, 타깃 14/30). 한 군데만 다른 쌍에서는 아직 진다
2. **시드 앙상블은 모든 GNN에 도움** — 과장이 줄고, GINE α=0 앙상블은 non-cliff에서 "항상 0"을 넘는다
3. **쌍 입력은 도움이 된다** — 같은 GINE의 분자별 예측보다 모든 칸에서 낫다
4. **개별 활성은 아직 SVR이 가장 정확하다.** Mole-BERT는 Δ를 잘 맞히고 기준별 흩어짐도 작지만 개별 값에서는 앞서지 못한다
5. **누수 점검** — 평가 분자의 1/3이 다른 타깃의 학습 분자였고 GNN은 그 분자에서 특히 잘 맞힌다.
   처음 보는 분자만 보면 Mole-BERT와 SVR의 cliff 오차는 거의 같다 (0.876 vs 0.883)
6. **non-cliff는 아직 SVR이 낫다**
