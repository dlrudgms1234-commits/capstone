# 쌍 기반 활성 차이 예측 (`ac_pipeline.ipynb`)

구조가 비슷한 두 분자 A, B를 한 번에 넣어 **활성 차이 Δ = p(B) − p(A)** 를 예측한다.
특히 구조는 거의 같은데 활성이 크게 다른 쌍(**activity cliff**, |Δ| ≥ 1 = 10배 이상 차이)을 잘 맞히는 것이 목표다.

## 1. 데이터와 쌍

- **데이터:** MoleculeACE 30개 타깃 (Ki 23개, EC50 7개), 분자 48,714개 (서로 다른 분자 35,633개)
- **분자 나누기:** train 64% · valid 16% · test 20% (MoleculeACE 분할 + train 분자의 20%를 valid로)
- **쌍 만들기:** 같은 타깃 안에서 지문 유사도(ECFP4 Tanimoto)가 0.5 이상인 두 분자를 쌍으로 만든다
  - **train: 유사 쌍 전부** — 유사도 조건만 만족하면 전부 (여러 군데 바뀐 쌍 포함)
  - **test: 한 군데만 다른 쌍** — 공통 구조(MCS)를 뺀 바뀐 부분이 한 덩어리이고 10원자 이하인 쌍.
    실제로 비교하는 후보 분자는 보통 한 군데만 다르기 때문이다
- **평가 원칙:** 모든 쌍에 **실측값을 아는 학습 분자가 하나 이상** 들어가게 한다.
  두 분자 모두 처음 보는 쌍을 Δ만으로 평가하면, 두 분자의 활성을 똑같이 틀려도(실제 3, 0을 13, 10으로) 정답 처리되기 때문이다

## 2. 모델

- 두 분자를 **두 번 읽는다** — 분자 전체(분자 인코더)와 바뀐 부분만(조각 인코더). 분자 표현은 원자 벡터의 평균
- 읽은 결과에 편집 정보(무엇이 몇 군데 바뀌었는지)와 타깃을 붙여 **예측 헤드(1,024 → 1,024 → 1)** 로 Δ를 바로 예측한다
  - 헤드는 MoleculeACE가 30개 타깃에서 튜닝한 MLP 설정(폭 1,024, 드롭아웃 0)을 모든 신경망에 똑같이 쓴다. 처음의 폭 64 한 층은 병목이었다
- 인코더는 두 가지를 비교한다
  - **GINE:** 그래프 신경망(3층, 폭 300), 처음부터 학습. 폭 300은 분자 그래프 신경망의 표준 폭이자 Mole-BERT와 같은 폭이다
  - **Mole-BERT:** 200만 분자로 미리 학습된 그래프 신경망(5층, 폭 300)을 가져와 미세조정 (인코더 학습률 1e-4, 헤드 1e-3)
- **최적화:** AdamW, 가중치 감쇠 0.01. 감쇠가 약하면 train 오차가 valid의 1/3 수준까지 내려가며 외우는 경향이 있어서 넣었다 (valid로 채택)
- **비교 대상:** **ECFP + SVR**(ECFP4 2,048비트, Tanimoto 커널, 타깃마다 따로 학습) — 분자별 예측 후 빼기와 쌍 입력(쌍 커널 T(A,C)·T(B,D)) 둘 다 /
  같은 인코더로 분자별 예측 후 빼기(쌍 입력이 정말 도움이 되는지 보기 위해). 분자별과 쌍은 인코더·읽기·헤드·최적화가 모두 같고 입력 형태만 다르다
- **데이터 구분:** train(유사 쌍 전부) / valid(train 분자 20%가 들어간 쌍) / test(MoleculeACE 평가 분자가 들어간 한 군데만 다른 쌍 38,711개)
  - 모델 안의 설정(멈출 에폭, SVR의 C)은 쌍은 valid 쌍 전체, 분자별은 valid 분자의 활성으로 정한다
  - 설계 비교는 **한 군데만 다른 valid 쌍**(28,565개)으로 하고, test는 고른 뒤 한 번만 연다. 모든 결정과 시점은 `experiments/계획_고정_2026-10-18.md`
- 신경망은 같은 설정을 **시드 5개**로 학습하고, 쌍마다 예측을 평균한 **시드 앙상블**로 비교한다 (SVR은 시드가 없다)

## 3. 지금까지 결과

test 쌍마다 **아는 분자(A) 실측 + 예측 Δ → 예측 B** 를 만들어 **B 실측과 비교한 RMSE** (pKi 단위, 낮을수록 좋음).

**주 결과 — AdamW 0.01 설정, test 첫 번째 열기 (10-20)** (test 쌍 38,711개, cliff 8,778개, 신경망은 시드 5개 앙상블)

| 입력 | 모델 | cliff | non-cliff | 전체 | 시드별 cliff | 시드별 non-cliff | 시드별 전체 |
|---|---|---|---|---|---|---|---|
| 분자별 | ECFP + SVR | 0.914 | 0.455 | 0.591 | – | – | – |
| 분자별 | GINE | 0.947 | 0.473 | 0.614 | 1.020 ± 0.104 | 0.560 ± 0.016 | 0.692 ± 0.044 |
| 분자별 | Mole-BERT | 1.122 | 0.540 | 0.715 | 1.161 ± 0.042 | 0.598 ± 0.003 | 0.763 ± 0.015 |
| 쌍 | ECFP + SVR | 0.911 | 0.448 | 0.586 | – | – | – |
| 쌍 | **GINE** | **0.863** | **0.447** | **0.569** | 0.886 ± 0.004 | 0.474 ± 0.004 | 0.593 ± 0.004 |
| 쌍 | Mole-BERT | 0.872 | 0.456 | 0.577 | 0.881 ± 0.008 | 0.467 ± 0.002 | 0.587 ± 0.003 |

앞 세 열 = 시드 5개 예측 평균(앙상블), 뒤 세 열 = 시드별 단일 모델의 평균 ± 표준편차. SVR은 시드가 없다.

**검정** (차이 [평가 분자 단위 군집 부트스트랩 95% 신뢰구간], 나은 타깃 수 / 30, 타깃 단위 Wilcoxon). 유의 = p < 0.05이고 신뢰구간이 0을 포함하지 않음

| 비교 | cliff | non-cliff | 전체 |
|---|---|---|---|
| **쌍 GINE − 쌍 SVR** | **−0.049** [−0.069, −0.029], 24, p = 0.0006 **유의** | −0.001 [−0.009, +0.007], 14, p = 0.95 | **−0.018** [−0.028, −0.007], 23, p = 0.011 **유의** |
| 쌍 Mole-BERT − 쌍 SVR | **−0.039** [−0.063, −0.014], 24, p = 0.0002 **유의** | +0.008 [−0.003, +0.018], 10, p = 0.096 | −0.009 [−0.021, +0.004], 19, p = 0.13 |
| 쌍 GINE − 분자별 GINE | **−0.084** (8.9%), 27, p < 0.001 **유의** | −0.026, 22, p = 0.003 **유의** | −0.045, 25, p < 0.001 **유의** |
| 쌍 Mole-BERT − 분자별 Mole-BERT | **−0.250** (22.3%), 27, p < 0.001 **유의** | −0.084, 29, p < 0.001 **유의** | −0.137, 29, p < 0.001 **유의** |
| 쌍 SVR − 분자별 SVR | −0.002, 10, p = 0.20 | −0.007, 20, p = 0.10 | −0.005, 16, p = 0.89 |

- **쌍 GINE이 쌍 SVR을 cliff와 전체에서 유의하게 이긴다.** non-cliff는 대등하다
- **쌍 Mole-BERT는 cliff에서 쌍 SVR을 유의하게 이긴다.** 전체·non-cliff는 차이가 유의하지 않다
- **쌍 입력은 그래프 모델에서 모든 지표를 유의하게 좋게 한다.** SVR에서는 효과가 없다
- 분자별 → 쌍의 cliff 감소는 Mole-BERT 22.3%, GINE 8.9%다. GINE은 분자별 모델도 강해서(분자별 SVR과 비슷한 수준) 차이가 작다
- **단일 모델(시드별 평균)로도 쌍 그래프 모델은 cliff에서 쌍 SVR보다 낮다** (GINE 0.886, Mole-BERT 0.881 vs 0.911). non-cliff·전체는 단일 모델로는 SVR보다 조금 높고(0.467–0.474, 0.587–0.593), 시드 앙상블로 SVR과 같거나 낮아진다. 논문에는 두 가지를 모두 보고한다
- 숫자 출처: `experiments/final3/test_result_1.txt`, 스크립트 `experiments/final3/final3_eval.py`. 노트북 11번에서도 같은 표와 검정이 나온다

**누수 처리:** 30개 타깃을 모델 하나로 학습하면, 한 타깃의 test 분자가 다른 타깃에서는 train 분자일 수 있다(test 분자의 약 40%).
이런 분자는 다른 타깃의 train·valid에서 뺀다(test 분할은 MoleculeACE 그대로). 그냥 두면 그래프 쌍 모델의 성능이 부풀려진다.

## 4. 개선 시도와 남은 실험

설계는 valid로만 비교해 골랐다. 처음 시도들은 시드 3개, 10-18부터는 한 군데만 다른 valid 쌍에서 시드 5개 앙상블로 비교했다.
자세한 숫자와 결정 시점은 `experiments/계획_고정_2026-10-18.md`에 있다.

**반영한 것**

| 시도 | 효과 |
|---|---|
| 예측 헤드: 폭 64 한 층 → 1,024 → 1,024 | 쌍·분자별 모두 cliff 오차가 크게 줄었다 (예: 쌍 GINE 1.083 → 0.914) |
| 누수 분자 빼기 | 그대로 두면 그래프 쌍 모델의 성능이 부풀려진다 |
| 학습은 유사 쌍 전부, 평가는 한 군데만 다른 쌍 | Mole-BERT 쌍 오차 0.778 → 0.715 |
| GINE 폭 64 → 300 | 쌍 GINE valid 0.642 → 0.589 |
| AdamW 가중치 감쇠 0.01 | 0.605 → 0.588 (외우기를 줄임) |
| 시드 3개 → 5개 앙상블 | 앙상블 이득 |
| 조각 인코더·편집 정보 유지, 쌍 판정 고치기 | 빼거나 되돌려도 차이가 없었다. 바뀐 부분 정보를 살리는 쪽으로 둔다 |

**반영하지 않은 것**

| 시도 | 결과 |
|---|---|
| 차이가 큰 쌍에 손실 가중치 (α) | 나아진 경우 없음 |
| cliff를 먼저 판단해 예측 줄이기 (게이트) | cliff 오차가 늘었다 |
| 그래프 모델을 타깃별로 학습 | 30개 타깃 한 모델보다 나쁨 (분자별 GINE 0.923 vs 0.752) |
| 분자 표현을 평균 대신 합으로 | 쌍 Mole-BERT 0.603 → 0.636 |
| 헤드 2,048 → 1,024 | 1,024 → 1,024보다 나쁨 (0.636 vs 0.607) |
| 한 군데만 다른 valid 쌍으로 학습 멈추기 | valid 쌍 전체로 멈추는 쪽이 나음 (0.615 vs 0.636) |
| 헤드 드롭아웃 0.2 / 인코더 학습률 3e-5 | AdamW(0.588)보다 나쁨 (0.619 / 0.644) |
| Mole-BERT 인코더 L2-SP (λ 0.01 / 0.1) | 0.575 → 0.577 / 0.585 |
| GINE 가중치 감쇠 0.03 | 0.559 → 0.560, 차이 없음 |

### 남은 실험

**지금 모델의 학습률과 가중치 감쇠**

| 모델 (쌍·분자별 같음) | 인코더 | 인코더 학습률 | 헤드 학습률 | AdamW 가중치 감쇠 |
|---|---|---|---|---|
| GINE | GINE 3층·폭 300, 처음부터 학습 | 1e-3 | 1e-3 | 0.01 (인코더·헤드 모두) |
| Mole-BERT | 사전학습 GIN 5층·폭 300, 미세조정 | 1e-4 | 1e-3 | 0.01 (인코더·헤드 모두) |

AdamW 감쇠는 매 단계 가중치를 (학습률 × 감쇠)만큼 0 쪽으로 줄인다. 그래서 같은 0.01이라도
Mole-BERT 인코더에는 GINE 인코더보다 10배 약하게 걸린다 (1e-4 × 0.01 = 1e-6, GINE은 1e-3 × 0.01 = 1e-5).

**누가 무엇을**

| 담당 | 실험 | 무엇이 어떻게 바뀌나 | 상태 |
|---|---|---|---|
| 박윤정 | Mole-BERT L2-SP (λ 0.01 / 0.1) | **Mole-BERT 인코더만** 바뀐다. 0 쪽으로 줄이는 AdamW 감쇠를 끄고, 매 단계 **사전학습 가중치 쪽으로** (1e-4 × λ)만큼 당긴다. 미세조정하면서 사전학습에서 너무 멀어지지 않게 하는 방식. 헤드는 그대로 (AdamW 0.01) | 끝, 채택 안 함 (0.575 → 0.577 / 0.585) |
| 팀원 | GINE 감쇠 0.03 | **GINE 인코더·헤드 모두** 감쇠 0.01 → 0.03. 매 단계 0 쪽으로 3배 세게 줄인다 (쌍·분자별 같은 값) | 끝, 차이 없음 (0.559 → 0.560) |
| 박윤정 | GINE 감쇠 0.02 | 위와 같은 방식으로 0.02 | 학습 중 (10-21 14:45 시작) |
| 박윤정 | Mole-BERT에 GINE 최적 감쇠 | GINE에서 0.02나 0.03이 0.01을 이기면, **Mole-BERT 인코더·헤드에도** 같은 감쇠를 걸어 다시 학습한다. 0.01이 그대로면 하지 않는다 | GINE 결과 후 |
| 함께 | test 다시 열기 | 설정이 바뀌면 test를 한 번 더 열고 논문 표·그림·노트북을 갱신한다 | 튜닝 후 |

**규칙:** 비교는 한 군데만 다른 valid 쌍에서 시드 5개 앙상블의 전체 오차로 한다. 보고는 시드 앙상블과 시드별 평균 ± 표준편차를 cliff / non-cliff / 전체 모두 쓰고, 학습 곡선을 남긴다.
도구는 `experiments/tune/` (`make_tune.py` → `run_queue.py` → `tune_eval.py`).
