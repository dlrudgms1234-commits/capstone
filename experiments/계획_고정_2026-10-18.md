# 최종 실험 계획 (결과를 보기 전에 고정, 2026-10-18)

이 문서는 최종 학습을 시작하기 전에 적었다. 평가 결과를 본 뒤에는 아래 내용을 바꾸지 않는다.

## 1. 모델 (6개)

| 입력 | 모델 | 학습 단위 | 고르는 기준 (검증 데이터) |
|---|---|---|---|
| 분자별 | ECFP + SVR (ECFP4 2,048비트, Tanimoto 커널) | 타깃별 | C ∈ {1, 10, 100, 1000}, 검증 분자의 활성 오차 |
| 쌍 | ECFP + SVR (쌍 커널 T(A,C)·T(B,D), 두 방향 학습, 반대칭 평균) | 타깃별 | C ∈ {1, 10, 100, 1000}, 검증 쌍의 Δ 오차 |
| 분자별 | GINE, Mole-BERT | **타깃별** | 검증 분자의 활성 오차가 20에폭 연속 나아지지 않으면 멈춤 (상한 1,000) |
| 쌍 | GINE, Mole-BERT (분자 표현 + 변화 부위 표현 + 편집 정보) | **타깃별** | 검증 쌍의 Δ 오차가 20에폭 연속 나아지지 않으면 멈춤 (상한 1,000) |

- 공통: 누수 분자 빼기(다른 타깃의 평가 분자는 학습·검증에서 뺌), 같은 학습·검증·평가 쌍
- 신경망 공통: 예측 헤드 1,024 → 1,024 → 1 (MoleculeACE가 튜닝한 MLP 설정), 학습률 1e-3 (Mole-BERT 인코더 1e-4), 묶음 256, 가중치 감쇠 1e-4
- 신경망 시드: **0, 1, 2, 3, 4 (5개)**. 예측은 시드 5개의 평균

## 2. 학습 단위 확인 (검증 데이터로만)

타깃별 학습이 30개 타깃 한 모델 방식(이미 학습된 시드 0–2)보다 **검증 데이터에서** 나쁜지 먼저 본다.
- 비교: 그래프 4개 모델 각각, 시드 0–2 평균 예측의 검증 쌍 Δ 오차 (분자별은 두 분자 예측의 차이)
- 타깃별이 나쁜 모델은 한 모델 방식으로 되돌리고 시드 3, 4를 더 학습한다. 이 판단은 평가 결과를 보기 전에 한다

## 3. 평가 (한 번)

- 평가 쌍: 한 군데만 다른 쌍 38,711개 (cliff 8,778개)
- **주 결과:** 평가 쌍 전체로 계산한 RMSE (cliff / non-cliff / 전체)
- 함께 보고: 타깃별 RMSE의 평균, 시드별 값
- 검정 (cliff RMSE, 두 가지를 모두 보고):
  1. 타깃 30개에 대한 양측 Wilcoxon 부호순위 검정
  2. 평가 분자 단위 군집 부트스트랩 2,000회의 95% 신뢰구간
  - 유의하다고 쓰는 조건: Wilcoxon p < 0.05 이고 신뢰구간이 0을 포함하지 않음
- 비교 쌍: 분자별 → 쌍 (SVR, GINE, Mole-BERT 각각), Mole-BERT 쌍 vs SVR 쌍, GINE 쌍 vs SVR 쌍

## 4. 남은 실험 계획 (10-20 통일, 우리·팀원 공통 — README와 같음)

- **고정:** AdamW 사용, GINE 폭 300, 조각 인코더 있음, 평균 읽기, 헤드 1,024 → 1,024 → 1, 누수 분자 빼기, 시드 0–4, 30개 타깃 한 모델. GINE + Mole-BERT 예측 평균은 쓰지 않는다
- **바꾸는 것:** 가중치 감쇠 쪽만. GINE은 감쇠 값(팀원, 0.03부터), Mole-BERT는 L2-SP(박윤정, 진행 중). 쌍과 분자별에 같은 값
- **GINE 감쇠 순서 (10-20 사용자 결정, 결과를 보기 전):** 0.03 먼저. 0.01(지금)과 비교해 좋으면 → 0.1 / 조금 나쁘면(차이 0.005 이내) → 0.02 / 확실히 나쁘면(0.005 초과) → 0.01 유지하고 튜닝 종료. 시간 때문에 그 이상 좁혀 가는 탐색은 하지 않는다
- **고르는 기준:** 한 군데만 다른 valid 쌍, 시드 5개 앙상블의 전체 오차. 시드 하나로 고르지 않는다
- **Mole-BERT 순서 (10-20 사용자 결정, 결과를 보기 전):** ① L2-SP 1단계로 λ 결정(채택/미채택) ② 팀원 GINE 튜닝으로 최적 감쇠 결정 ③ Mole-BERT 쌍·분자별을 [② 감쇠 (헤드에, L2-SP 미채택이면 인코더에도) + ① 결과]로 시드 5개 학습 ④ 지금 Mole-BERT(최종 설계 3 또는 ①)보다 valid가 좋으면 채택, 아니면 유지. ②가 0.01 그대로면 ③④는 생략
- **보고:** 시드 앙상블과 시드별 평균 ± 표준편차를 cliff / non-cliff / 전체 모두. 학습 곡선을 반드시 남긴다 (`experiments/tune/tune_eval.py val`이 자동 저장, 노트북 학습 곡선 셀도 `runs/curves_*.png` 저장)
- **test:** 고른 뒤 한 번만 열고 여기에 "n번째 열기"와 결과를 기록 (`experiments/tune/tune_eval.py test`)
- 빼기 실험은 시간이 없어 하지 않는다 (10-20 사용자 결정)
- 도구: `experiments/tune/make_tune.py` (작업 만들기) → `run_queue.py` (학습) → `tune_eval.py` (valid·test 비교, 학습 곡선)
