# 그래프클리프 로그

GraphCliff 인코더로 바꾼 쌍 모델(5시드)과 분자별 모델(5시드)의 학습 기록. 인코더만 바뀌고 나머지는 GINE 쌍/분자별 모델 그대로다.
평가는 valid만 썼고 test는 열지 않았다. 시각은 2026-10-22~23, 서버 시계 기준.

## 설정 (공통)
- 인코더: GraphCliff (AtomEncoder + GraphCliffFilter ×3 = ShortGINE + LongPoly Chebyshev + gating, groups=4, mid_K=3, dropout 0.1). 원본의 SAGPooling·회귀 헤드는 뺐다 (`experiments/tune/graphcliff_enc.py`)
- 은닉 300, 층 3, 배치 256, 학습률 1e-3, AdamW 감쇠 0.01, 헤드 1024→1024→1, 평균 읽기, 누수 분자 제외(drop_leak), 타깃 30개, 타깃 one-hot 입력
- 시드 0~4, GPU 0~4번 (시드마다 작업 하나)
- 만든 스크립트: `make_gc.py --kind mol|pair`, 실행 `run_multi.py`, 평가 `eval_gc.py`(분자 축) · `tune_eval.py val`(쌍 축)
