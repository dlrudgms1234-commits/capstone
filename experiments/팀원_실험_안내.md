# 팀원 실험 안내: ① 성능 차이 유의성 검정 ② 조각 인코더 빼기

이 두 실험을 바로 할 수 있게 예측값과 도구를 저장소에 넣었다. ①은 **학습이 필요 없고 1분**이면 되고, ②는 GPU로 다시 학습해야 한다.

| 쓰는 것 | 무엇 |
|---|---|
| `experiments/preds/preds_test.csv.gz` | test 쌍 38,711개(cliff 8,778)의 모델별 예측 Δ̂ (시드마다 한 열) |
| `experiments/preds/preds_val.csv.gz` | 한 군데만 다른 valid 쌍 28,565개(cliff 6,411)의 같은 내용 |
| `experiments/tune/sig_test.py` | 위 파일로 성능 표와 유의성 검정 |
| `experiments/tune/export_preds.py` | 예측값 파일 만들기 / **내 모델 열 더하기** |
| `experiments/tune/make_tune.py --drop frag` | 조각 인코더를 뺀 모델 학습 준비 |

예측값 파일의 열: `target, i, j, delta`(실측 Δ), `is_cliff`, `eval_mol`(쌍에서 학습 분자가 아닌 쪽 = 검정에서 묶는 단위), 그리고 `<모델>_s0 … <모델>_s4`.

| 모델 이름 | 무엇 |
|---|---|
| `svr_mol` / `svr_pair` | ECFP + Tanimoto 커널 SVR, 분자별 / 쌍 (타깃마다 학습, 시드 없음) |
| `gine_mol` / `gine_pair` | GINE 3층·폭 300, 분자별 / 쌍 |
| `mb_mol` / `mb_pair` | **Mole-BERT 사전학습, 인코더 학습률 1e-3 (지금 가장 좋은 설정)**, 분자별 / 쌍 |
| `mb_pair_lr1e4` | Mole-BERT 쌍, 인코더 학습률 1e-4 (예전 설정) |
| `mb_pair_noedit` / `mb_pair_notgt` / `mb_pair_noedit_tgt` | `mb_pair`에서 편집 정보 / 타깃 one-hot / 둘 다 뺀 것 (이미 끝난 빼기 실험) |
| `mb_pair_scratch` | Mole-BERT 구조에 사전학습 가중치를 안 쓴 것 (인코더 1e-4) |

## ① 성능 차이 유의성 검정

```bash
python experiments/tune/sig_test.py experiments/preds/preds_test.csv.gz                   # 전체 표 + 기본 비교
python experiments/tune/sig_test.py experiments/preds/preds_test.csv.gz mb_pair svr_pair  # 원하는 두 모델만 (여러 쌍 이어서 가능)
```
필요한 것은 python + pandas + scipy뿐이다 (가중치·GPU·데이터 없이 돌아간다).

**검정 두 가지를 같이 본다. 둘 다 만족할 때만 "유의"로 쓴다.**

- **타깃 단위 Wilcoxon 부호 순위**: 타깃 30개의 RMSE를 짝지어 비교 (p < 0.05)
- **군집 부트스트랩 95% 신뢰구간**: 같은 평가 분자가 들어간 쌍을 한 덩어리로 묶어 2,000번 다시 뽑는다 (구간이 0을 넘지 않아야 함).
  한 분자가 여러 쌍에 들어가므로 쌍을 따로따로 세면 구간이 실제보다 좁아진다

**이미 나온 결과** (test, 시드 5개 앙상블. 음수 = 앞 모델이 낫다)

| 비교 | cliff | non-cliff | 전체 |
|---|---|---|---|
| 쌍 Mole-BERT − 쌍 SVR | **−0.059** [−0.082, −0.037], 27/30, p = 1.7e-06 **유의** | +0.006, 10/30, p = 0.11 | **−0.017** [−0.029, −0.005], 21/30, p = 0.003 **유의** |
| 쌍 GINE − 쌍 SVR | **−0.049** [−0.069, −0.029], 24/30, p = 0.0006 **유의** | −0.001, 14/30, p = 0.95 | **−0.018** [−0.028, −0.007], 23/30, p = 0.011 **유의** |
| 쌍 Mole-BERT − 분자별 Mole-BERT | **−0.166**, 28/30, p < 0.001 **유의** | **−0.058** 유의 | **−0.092** 유의 |
| 쌍 GINE − 분자별 GINE | **−0.084**, 27/30, p < 0.001 **유의** | **−0.026** 유의 | **−0.045** 유의 |
| 쌍 SVR − 분자별 SVR | −0.002, 10/30, p = 0.2 | −0.007, 20/30, p = 0.1 | −0.005, 16/30, p = 0.89 |
| 쌍 Mole-BERT − 쌍 GINE | −0.010 [−0.030, +0.009], 21/30, p = 0.005 → 구간이 0을 넘어 **유의하지 않음** | +0.007 | +0.001 |

읽는 법: 쌍 입력은 **그래프 모델에서만** 모든 구간에서 유의하게 좋아지고(SVR은 차이 없음), 쌍 그래프 모델은 cliff와 전체에서 쌍 SVR보다 유의하게 낫다.
Mole-BERT와 GINE 사이에는 유의한 차이가 없다.

**내 모델(GraphCliff 등)을 같은 표에 넣기** — 내 예측 파일을 열로 더한 새 파일을 만든다.

```bash
python experiments/tune/export_preds.py test 내비교.csv.gz --add experiments/preds/preds_test.csv.gz \
    "gc_pair=runs/tune/gc_pair/pred_*_s?.pkl" "gc_mol=runs/tune/gc_mol/pred_mol_*.pkl"
python experiments/tune/sig_test.py 내비교.csv.gz gc_pair svr_pair
```
- 쌍 모델은 시드마다 파일 하나(열 이름이 `pred_`로 시작), 분자별은 파일 하나에 시드 열 `s0…s4`(활성 예측), SVR은 `pred` 열 하나면 알아서 읽는다
- 쌍 번호(`target, i, j`)로 맞추므로 쌍 순서가 달라도 되고, 빠진 쌍이 있으면 바로 알려 준다
- valid로 보려면 `test` → `val`, `preds_val.csv.gz`로 바꾼다

## ② 조각 인코더 빼기

**조각 인코더**는 두 번째 인코더로, 쌍에서 **바뀐 부분의 원자만** 읽어 `f(A)`, `f(B)`를 만든다.
빼면 헤드 입력이 `[h(A), h(B), h(B)−h(A), f(A), f(B)]`(폭 300 × 5칸)에서 **앞 3칸만** 남고, 편집 정보 6칸과 타깃 one-hot은 그대로다.
즉 **"바뀐 부분을 따로 읽는 것이 정말 필요한가"** 를 보는 실험이다. 분자 인코더는 그대로라 비교가 깨끗하다.

```bash
# 기준 모델 = Mole-BERT 사전학습 + 인코더 학습률 1e-3 (쌍 모델, 시드 0–4)
python experiments/tune/make_tune.py --name mb_nofrag --enc mb --pt-lr 1e-3 --drop frag --no-mol
python experiments/tune/run_queue.py runs/tune/mb_nofrag 3        # 동시 3개. GPUS=2,3,4 처럼 카드를 지정할 수 있다
python experiments/tune/tune_eval.py val runs/tune/mb_nofrag      # valid 표 + 학습 곡선 (runs/tune/mb_nofrag/curves_*.png)
```
- GINE으로도 보려면 `--name gine_nofrag --enc gine --drop frag --no-mol` (학습률 옵션 없이)
- `--drop frag,edit` 처럼 같이 빼도 된다. 가중치 이름에 `_nofrag`가 붙어 기존 가중치와 섞이지 않는다
- 준비물: 쌍 캐시 `data/pairs/*_v2.pkl`와 `runs/pretrained/Mole-BERT.pth` (Release `capstone_cache_2026-10-12.tar.gz`에 들어 있다)
- 시간: 시드 하나 3시간 안팎, 동시 3개면 대여섯 시간 (A100 기준)

**비교 기준값** (같은 설정에서 입력만 다름. cliff / non-cliff / 전체)

| 입력 | valid (한 군데만 다른 쌍) | test |
|---|---|---|
| 전체 입력 (`mb_pair`) | 0.838 / 0.431 / **0.549** | 0.852 / 0.454 / **0.569** |
| 편집 정보 뺌 | 0.846 / 0.440 / 0.557 | 0.851 / 0.460 / 0.573 |
| 타깃 one-hot 뺌 | 0.942 / 0.477 / 0.613 | 0.931 / 0.475 / 0.609 |
| 둘 다 뺌 | 0.945 / 0.483 / 0.617 | 0.940 / 0.486 / 0.619 |
| **조각 인코더 뺌** | ← 이 실험 | |

**보고 방식 (우리 규칙)**

- 비교는 **한 군데만 다른 valid 쌍, 시드 5개 앙상블의 전체 오차**로 한다. 시드 하나로 판단하지 않는다
- 앙상블 값과 **시드별 평균 ± 표준편차**를 cliff / non-cliff / 전체 모두 적는다 (`tune_eval.py val`이 둘 다 찍어 준다)
- 학습 곡선을 반드시 남긴다 (`tune_eval.py`가 자동 저장)
- 차이가 시드 흔들림(표준편차 0.003–0.006)보다 작으면 "차이 없음"으로 쓴다
- **test는 설정을 고르는 데 쓰지 않는다** (이미 두 번 열었고, 기록은 `experiments/계획_고정_2026-10-18.md`).
  빼기 실험은 기여를 보는 실험이라 test 표에 참고로 같이 적는 것은 괜찮다. 그때는 예측을 열로 더해서 같은 표에 넣는다:
  ```bash
  python experiments/tune/export_preds.py test 내비교.csv.gz --add experiments/preds/preds_test.csv.gz \
      "mb_pair_nofrag=runs/tune/mb_nofrag/pred_mb_s?.pkl"
  python experiments/tune/sig_test.py 내비교.csv.gz mb_pair_nofrag mb_pair
  ```
- 결과는 `experiments/계획_고정_2026-10-18.md`에 날짜·수치와 함께 한 줄 적는다 (우리 기록 방식)
