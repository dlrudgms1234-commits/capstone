## 이번에 반영한 것
- **글꼴 통일:** Word로 고친 판에서 그림 캡션과 표가 Apple SD Gothic Neo와 Helvetica로 바뀌어 있었다. 모든 글자를 함초롬돋움으로 지정해 다시 생성했다. 예외는 예측값 기호 Δ̂ 하나로, 함초롬돋움에서는 모자가 Δ 위에 얹히지 않아 Helvetica로 두었다.
- **제목:** 5.1의 의도(실측 기준 분자로 보지 못한 분자를 예측)와 Mole-BERT 쌍 입력을 담았다.
  - 국문: 실측 기준 분자와 Mole-BERT 쌍 입력을 이용한 Activity Cliff 활성 예측
  - 영문: Activity Cliff Prediction from Measured Anchor Molecules with a Pair-Input Mole-BERT Model
- **그림 2(새로 추가):** 분자별 Mole-BERT 모델 구조. 그림 1과 같은 양식과 같은 예시 쌍을 썼다. 3.2절에 설명 문단을 넣었다. 기존 그림 2(타깃별 막대)는 그림 3이 되었고, 4.2절에서 "(그림 3)"으로 인용한다.
- **그림 색:** 그림 1과 2에 옅은 색을 넣었다.
  - 분자 경로: 옅은 녹회색
  - 변화 부위 경로와 바뀐 원자: 남색 계열
  - 편집 정보·타깃: 옅은 회색
  - 그림 2에는 남색이 없어서, 변화 부위를 쓰지 않는다는 점이 한눈에 보인다.
- **표 1:** 2쪽 오른쪽 단 가운데, 4.1 본문 바로 뒤에 잘리지 않고 놓인다. 행이 쪼개지지 않게 설정했고(cantSplit), 표 제목·표·주석이 함께 움직인다. 굵은 글씨는 Word 판대로 분자별·쌍 각각의 열 최솟값이다.
- **고친 사실관계 (Word 판 문장 기준):**
  - 3.3: "최대 학습은 쌍 입력 8에폭·분자별 20에폭으로 제한했다"를 "검증 RMSE가 쌍 입력은 8에폭, 분자별은 20에폭 연속 개선되지 않으면 학습을 종료했다"로 고쳤다. 8·20은 상한이 아니라 기다리는 에폭 수이고, 실제 상한은 200·1,000이다.
  - 결론: "(0.914 대 0.889)"는 순서가 뒤바뀌어 있었다. "(Mole-BERT 쌍 입력 0.889, ECFP+SVR 0.914)"로 고쳤다.
- 그 밖의 문장은 Word 판과 글자 하나까지 같다(자동 대조).
