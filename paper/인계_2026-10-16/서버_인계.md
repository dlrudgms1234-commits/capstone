## 1. 실험 A: 변화 부위 인코더 빼기

### GINE
- 셀 `18184d19`에서 `USE_FRAG, USE_EDIT = False, True`로 바꾸고 쌍 모델을 학습한다. tag 끝이 `..._nofrag_head1024_leakdrop`이 된다.
- 시드를 GPU에 나눠 돌리려면 `experiments/make_ablC.py`를 본떠 조건만 바꾼다. 거기서 `noedit`을 고치는 줄을 `USE_FRAG, USE_EDIT = False, True`로 바꾸면 된다. 그 스크립트는 예전 설정이므로 위 표의 `LEAK_MODE`와 `HEAD`도 함께 바꿔야 한다.

### Mole-BERT (코드 수정 필요)
지금 `PTPairModel`(셀 `molebert-train`)은 `use_frag = True`로 박혀 있어서 `USE_FRAG`를 무시한다. 아래처럼 고친다. `USE_FRAG = True`일 때는 지금과 구조가 같으므로 기존 가중치를 그대로 불러온다.

```python
class PTPairModel(PairModel):
    """쌍 모델에서 두 인코더만 Mole-BERT로 바꾼다. 이어 붙이기·헤드·손실은 그대로"""
    def __init__(self):
        nn.Module.__init__(self)
        self.use_frag, self.use_edit = USE_FRAG, USE_EDIT          # ablation 옵션을 GINE과 같이 따른다
        self.mol = MoleBERT()
        self.frag = MoleBERT() if self.use_frag else None
        n_in = (5 if self.use_frag else 3) * PT_DIM + (N_EDIT if self.use_edit else 0) + len(DEV_TARGETS)
        self.head = make_head(n_in)

    def param_groups(self):
        enc = list(self.mol.parameters()) + (list(self.frag.parameters()) if self.frag is not None else [])
        return [{'params': enc, 'lr': PT_LR}, {'params': self.head.parameters(), 'lr': LR}]
```

- `PairModel.forward`는 `self.use_frag`가 False면 f(A), f(B)를 건너뛴다(셀 `3c8f160f`). Mole-BERT tag는 `TAGS[setting] + '_molebert'`라 `_nofrag`가 자동으로 붙는다.
- 이 조건의 파라미터 수가 줄었는지(Mole-BERT 인코더 하나 분량, 약 186만 개) 셀 끝의 `Mole-BERT 쌍 모델 파라미터` 출력으로 확인한다.

### (선택) 변화 부위 인코더와 편집 정보 둘 다 빼기
`USE_FRAG, USE_EDIT = False, False`. 시간이 남을 때만 한다.

## 2. 실험 B: 쌍 입력 ECFP + SVR

`experiments/ecfp/ecfp_mlp.py`의 데이터 부분을 그대로 가져다 새 스크립트 `ecfp/ecfp_svr_pair.py`를 만든다. 분할, 누수 규칙(`drop_leak`), 쌍 캐시 `data/pairs/*_v2.pkl`의 train / val_easy / test_easy가 여기에 해당한다. 모델만 SVR로 바꾼다.

| 항목 | 값 | 이유 |
|---|---|---|
| 학습 단위 | 타깃마다 따로 30개 | 분자별 ECFP + SVR과 같게 |
| 지문 | ECFP4 2,048비트(반지름 2) | 분자별 SVR과 같게 |
| 쌍 커널 | K((A, B), (C, D)) = T(A, C) · T(B, D), T = Tanimoto | 두 분자를 순서대로 비교하는 표준 쌍 커널 |
| 정답 | Δ = p(B) − p(A) (학습 쌍 한 방향) | |
| 예측 | Δ̂ = [g(A, B) − g(B, A)] / 2 | 쌍 신경망과 같은 반대칭 처리 |
| C | {1, 10, 100, 1000} 중 검증 쌍 RMSE가 가장 낮은 값 | 분자별 SVR과 같은 후보 |
| ε | 0.1 (기본값) | |
| 시드 | 없음 (결정적) → 열 하나 `svr_pair` | |

- **메모리.** 학습 쌍이 가장 많은 타깃은 CHEMBL2971_Ki로, 누수 제외 전 한 방향 32,010쌍이다(맥 캐시에서 셈). 커널 행렬은 32k × 32k float64로 약 8GB가 된다. 한 방향만 학습하고 예측 때 양방향 평균을 내면 서버에서 감당할 수 있다. 메모리가 모자라면 그 타깃만 학습 쌍 20,000개를 시드 0으로 무작위 추출하고, 그 사실을 표 주석에 적는다.
- 커널 계산: 학습·평가 분자의 Tanimoto 행렬 T를 한 번 구한다. 쌍 커널은 `T[a_i][:, a_j] * T[b_i][:, b_j]`로 만들고, `sklearn.svm.SVR(kernel='precomputed')`에 넣는다.
- (선택 대안) 차이 커널 K = T(B, D) − T(B, C) − T(A, D) + T(A, C)는 반대칭이 자동으로 성립한다. 시간이 남으면 이것도 돌려 보고, 둘 중 검증 쌍에서 나은 쪽을 쓴다. 어느 쪽을 골랐는지는 반드시 적는다.

## 4. 논문에 넣는 방법

- **위치.**
  - 변화 부위 인코더 결과는 4.2절 끝에 "표 2 쌍 입력 구성 요소별 평가 RMSE"로 넣는다(1단 표, 약 9줄).
  - 쌍 SVR은 표 1에 "쌍 | ECFP + SVR" 행으로 넣는다.
  - 지금 3쪽 오른쪽 단의 여백은 약 60 mm(단 높이의 25%)로, 대략 표 하나 분량이다. 문장을 더 늘리면 4쪽이 되니, 늘린 만큼 다른 문장을 줄인다.
- **해석은 결과를 보기 전에 정해 둔다.**
  - 변화 부위 인코더를 빼서 cliff가 유의하게 나빠지면(Wilcoxon p < 0.05, CI가 0을 넘지 않음): "변화 부위를 따로 표현하는 것이 cliff 예측에 기여한다"고 쓴다.
  - 차이가 유의하지 않으면: "쌍 입력의 이득은 주로 두 분자를 함께 보고 기준 분자로 채점하는 설계에서 오며, 변화 부위 인코더의 추가 기여는 작다"고 쓴다. 이때 2절 관련 연구와 3.2절의 변화 부위 인코더 설명은 기여를 과장하지 않게 고친다.
  - 쌍 SVR이 분자별 SVR보다 cliff에서 나으면: 쌍 입력의 효과가 모델 종류와 무관하다는 근거가 된다. 나쁘거나 비슷하면: 그래프 신경망에서 특히 큰 효과라고 범위를 좁혀 쓴다.
- **반영 순서.**
  1. `src/build.js`에서 표와 문장을 고친다(문장은 사용자가 Word로 고친 판을 옮긴 것이므로 그 문체를 유지한다).
  2. `_log/ksc_s2.md` 2절 수치 장부에 새 수치와 출처를 적는다.
  3. `bash src/verify.sh`를 돌린다. 마지막 줄이 `ALL PASS`이고 쪽수가 3이어야 한다.
  4. `KSC2026_AC_Delta.pdf`를 `_build/`에서 복사해 갱신한다.
