## 2. 추가할 결과 (서버에서 실행 예정, 방법은 `서버_인계.md`)

변화 부위 인코더(f)를 빼면 입력은 h(A), h(B), h(B) − h(A), 편집 정보, 타깃만 남는다. 나머지(인코더, 헤드, 학습·평가 쌍, 시드)는 그대로 둔다.

| Mole-BERT | O | O | 0.889 | 0.471 | 0.592 | (기준) | | |
| Mole-BERT | X | O | 미정 | 미정 | 미정 | 미정 | 미정 | 미정 |
| Mole-BERT | X | X | (선택) | | | | | |

| GINE | X | O | 미정 | 미정 | 미정 | 미정 | 미정 | 미정 |

**미리 알아둘 점.** 예전 설정(작은 헤드, 누수 통제 전, 한 곳만 바뀐 쌍으로 학습, GINE)에서 해 본 같은 실험이 노트북 `ablation-md` 셀에 남아 있다. 결과는 cliff 1.149 → 1.187(변화 부위 인코더를 뺌), 1.154(인코더와 편집 정보를 둘 다 뺌)였다. 빼면 나빠지는 방향이지만 차이가 시드 사이 흔들림 안이었다. 설정이 달라 논문 수치와 바로 비교할 수는 없다. 다만 이번에도 차이가 작게 나올 수 있으니, 그 경우의 해석도 미리 정해 둔다(`서버_인계.md` 4절).

### 2-2. 쌍 입력 ECFP + SVR (쌍 SVR)

분자별 비교 대상 가운데 가장 강한 ECFP + SVR에 쌍 입력을 주었을 때도 cliff가 좋아지는지 본다. 그래야 "쌍 입력의 효과"가 그래프 신경망에만 있는 것인지 가릴 수 있다.

| 입력 | 모델 | cliff | non-cliff | 전체 | 분자별 SVR 대비 cliff 차이 [95% CI] | 나아진 타깃 | p |
