## 3. 핵심 주장 (하나로)

> **그래프 신경망은 분자를 하나씩 보는 대신 두 분자를 쌍으로 입력하면 activity cliff 예측 성능이 크게 향상된다.**
> 같은 인코더·같은 예측 헤드·같은 평가 쌍에서 cliff RMSE가 GINE 21.1%, Mole-BERT 23.3% 감소했고(각각 30/30, 28/30 타깃에서 개선),
> 그 결과 분자별로는 ECFP + SVR에 크게 뒤지던 그래프 신경망이 누수를 통제한 평가에서 ECFP + SVR과 대등한 수준(cliff 0.889 vs 0.914, 전체 0.592 vs 0.591)에 도달했다.

- **기여는 2개로:** ① 쌍 입력 그래프 신경망과 그 효과의 체계적 검증(두 인코더, 타깃별 검정) ② 기준 분자 채점·누수 통제를 갖춘 공정한 평가.
- 평가 설계(②)는 앞에 크게 내세우지 말고 **"공정하게 쟀다"는 신뢰의 근거**로 방법 절에 짧게.
- "SVR을 이긴다"고 쓰지 않는다. cliff는 대등(타깃 단위 p = 0.70), non-cliff는 SVR이 낮다.

## 4-1. 방법 절에 꼭 넣을 파이프라인 핵심 (설정값은 코드에서 확인한 값)

원고 3장에 아래 내용이 **빠짐없이, 이 순서로** 들어가야 한다. 각 항목은 "무엇을 했나 + 왜 했나"를 한두 문장씩.

### (1) 학습 쌍: 같은 타깃의 유사 쌍 전부

- **무엇:** 같은 타깃 안에서 ECFP4(Morgan 반지름 2, 2,048비트) Tanimoto 유사도 ≥ 0.5인 두 분자를 모두 쌍으로 만든다. 여러 곳이 바뀐 쌍도 포함한다. 학습 쌍 = 학습 분자끼리, 검증 쌍 = 검증 분자–학습 분자. 학습 쌍 266,115개, 두 방향(A→B, B→A)을 모두 학습에 쓴다.
- **분자 분할:** 평가 분할은 MoleculeACE를 그대로 따르고, 학습 분자의 20%를 무작위로 검증에 쓴다(시드 0).
- **왜 같은 타깃 안에서만:** 활성값은 타깃(실험 조건)마다 기준이 달라서, 다른 타깃 분자끼리의 차이는 구조 변화의 효과가 아니다.
- **왜 유사도 0.5:** 구조가 비슷한 분자끼리만 "무엇이 바뀌었나"를 정의할 수 있다. 0.5는 MCS 판정을 통과하는 쌍의 99.5%를 남기는 값이다.
- **왜 한 군데만 다른 쌍만 쓰지 않고 유사 쌍 전부로 학습하나:** 한 군데만 다른 쌍은 학습 데이터가 약 5배 적다. 여러 곳이 바뀐 쌍까지 보면서 더 일반적인 차이를 배운다. 실제로 유사 쌍 전부로 학습했을 때 한 군데만 다른 평가 쌍의 cliff 오차가 더 낮았다(이전 설정 기준 Mole-BERT 쌍 1.061 → 0.893). 이 수치는 누수 통제 전 설정이라, 원고에는 근거로 짧게만 쓰거나 생략한다.

### (2) 평가 쌍: 한 군데만 다른 쌍 + 기준 분자

- **무엇:** 평가 분자와 학습 분자의 쌍 중, 공통 최대 부분구조(MCS) 밖의 차이가 **한 덩어리이고 10원자 이하**인 쌍만 평가한다 (188,889쌍 중 38,711쌍, cliff 8,778쌍).
    - MCS: RDKit FindMCS, 원소·결합 차수 비교, 고리는 고리끼리만 대응, 시간 제한 5초
    - 제외: 여러 곳 변경 80,722, 10원자 초과 49,467, MCS 시간 초과 19,603, 입체만 다름 386
- **왜 한 군데만 다른 쌍:** 실제 신약 최적화는 기준 화합물에서 한 곳씩 바꿔 보는 유사체(matched molecular pair) 비교가 기본이다. 한 곳만 바뀌어야 "무엇이 바뀌어 활성이 얼마나 변했나"를 물을 수 있고, 바뀐 부위(조각)도 하나로 정해진다. 선별은 구조만 보고, 활성값·예측값은 쓰지 않는다.
- **기준 분자(anchor):** 모든 평가 쌍에는 실측값을 아는 학습 분자가 하나 들어간다. 평가 분자끼리의 쌍은 쓰지 않는다.
    - 이유: 두 분자를 모두 처음 보는 쌍을 Δ만으로 채점하면, 두 분자를 똑같이 틀려도(예: 실제 3, 0을 13, 10으로) Δ가 맞아 정답 처리된다.
- **cliff 정의:** 쌍 단위 \|Δ\| ≥ 1 (10배 이상 차이). MoleculeACE의 cliff는 분자 단위라서 수치를 직접 비교하지 않고, ECFP + SVR도 같은 정의로 다시 평가했다.

### (3) 손실과 예측: 기준 분자의 실측값에 Δ̂를 더한다

- **무엇:** 모델은 Δ̂ = p(B) − p(A)를 낸다. 학습 손실은 **"기준 분자 A의 실측값 + Δ̂"로 만든 B의 예측값과 B의 실측값의 제곱 오차**다.
    - 식: L = ( (p_A + Δ̂) − p_B )² = (Δ̂ − Δ)²
    - 모든 쌍을 같은 무게로 본다(보통 MSE). MoleculeACE 등 선행연구와 같은 방식이다.
- **왜 이렇게 했나:** 한 분자의 활성을 추정할 때, 실측값을 아는 분자를 **기준점**으로 두고 거기서의 변화량만 예측하게 하려는 것이다. 절대 활성을 처음부터 맞히는 대신 "아는 값 + 변화량"으로 추정하므로, 분자별 예측의 오차가 두 번 쌓이지 않고 추정이 기준점에 고정된다.
    - 평가도 같은 식이다: 평가 분자 B의 활성 = 기준 분자 A의 실측값 + Δ̂. 평가 RMSE는 이 B 추정값과 B 실측값의 RMSE(pKi·pEC50 단위)다.
    - 한 평가 분자에 기준 분자가 여러 개면 각 기준에서의 추정을 평균할 수 있다(평가 분자 하나에 평균 5.33개, 최대 76개).
- **정직하게 쓸 점:** p_A는 고정된 실측값이라, 학습 손실은 수식상 Δ 오차의 제곱과 같다. 즉 기준점 설계의 핵심은 **문제 정의와 채점 방식**(기준 분자가 있는 쌍만 쓰고, B를 A에서 추정)에 있다. 원고에 "손실 함수를 새로 설계했다"처럼 쓰지 않는다.
- **순서 대칭:** 학습에 A→B, B→A 두 방향을 모두 쓰고, 예측은 Δ̂ = [g(A, B) − g(B, A)] / 2 로 한다. 그래서 Δ̂(A, B) = −Δ̂(B, A), Δ̂(A, A) = 0이 항상 성립한다.

### (4) 모델 입력: 분자 표현 + 변화 부위 표현 + 편집 정보 + 타깃

- **분자 인코더:** 분자 전체 원자 벡터의 평균 → h(A), h(B)
- **변화 부위(조각) 인코더:** MCS 밖의 바뀐 원자만 평균 → f(A), f(B). 여러 곳이 바뀌면 모두 포함한다. MCS 시간 초과·입체만 다른 쌍은 f = 0
- 두 인코더는 구조가 같지만 가중치는 따로이고, A와 B는 같은 인코더를 쓴다
- **편집 정보 6칸** (바뀐 부위를 A·B에서 짝지어 계산):

| 칸 | 값 | 계산 |
|---|---|---|
| 교체 있음 | 0/1 | A의 바뀐 덩어리와 B의 바뀐 덩어리가 공통 구조의 같은 자리에 붙어 있으면 "교체" |
| 추가 있음 | 0/1 | B에만 있는 덩어리 |
| 삭제 있음 | 0/1 | A에만 있는 덩어리 |
| 부위 수 | 바뀐 곳 수 ÷ 4 (최대 1) | 덩어리 개수 |
| 바뀐 원자 수 | 바뀐 원자 수 ÷ 10 (최대 3) | A·B 중 큰 쪽 |
| 조각 있음 | 0/1 | 0이면 f = 0 (MCS 시간 초과·입체만 다름) |

- 앞 세 칸은 종류가 한 번이라도 있으면 1인 multi-hot이다 (한 쌍에 교체와 추가가 함께 있을 수 있음). 방향을 뒤집으면(B→A) 추가와 삭제를 바꿔 넣는다.
- 평가 쌍(한 군데만 다름)은 앞 세 칸 중 하나만 1, 부위 수 0.25다.
- **타깃 one-hot 30칸:** 30개 타깃을 한 모델로 학습하므로, 같은 분자 쌍도 타깃마다 Δ가 다르다(9,507개 분자가 둘 이상 타깃에 등장).
- **이어 붙인 입력 크기:** h(A), h(B), h(B) − h(A), f(A), f(B), 편집 6칸, 타깃 30칸
    - GINE: 64 × 5 + 6 + 30 = **356칸**
    - Mole-BERT: 300 × 5 + 6 + 30 = **1,536칸** (결과 보고 PDF에 "1,566칸"으로 잘못 적혀 있었음. 1,536이 맞다)
- **ablation(참고, 본문에 넣을지 선택):** 편집 정보 6칸을 빼도, 바뀐 원자 수 칸만 빼도 차이가 없었다(평가 bal 0.801 → 0.803 / 0.805, 시드 흔들림 0.005–0.015). 즉 모델이 "많이 바뀌면 차이가 크다"는 쉬운 단서에 기대지 않는다.

### (5) 예측 헤드: 1,024 → 1,024 → 1

- **구조:** 은닉층 2개(각 폭 1,024, ReLU) + 출력 1개. 드롭아웃 0.
- **왜 1,024를 두 번:** 비교 모델인 ECFP + MLP의 설정을 MoleculeACE에서 그대로 가져왔다. MoleculeACE가 30개 타깃마다 MLP를 튜닝한 결과, 은닉 폭은 **30개 타깃 모두 1,024**, 층 수는 **2층이 가장 많았다**(10/30). 이 헤드를 그래프 쌍 모델·분자별 모델·ECFP + MLP 쌍 **모두에 똑같이** 써서, 모델 간 차이가 **입력 표현과 입력 방식(쌍/분자별)에서만** 오도록 했다.
- "1,024가 두 번" = 폭 1,024인 은닉층이 두 개라는 뜻이다. (입력 → 1,024 → 1,024 → 1)
- 원고에는 "평가 결과를 보고 키웠다"가 아니라 **"용량 차이를 없애기 위해 통일했다"**로 쓴다.

### 5.2 새로 해야 할 검정 (이 CSV로 바로 가능)

- **ECFP + MLP 쌍 vs Mole-BERT 쌍 / GINE 쌍:** 타깃별 cliff RMSE Wilcoxon + 평가 분자 단위 군집 부트스트랩 95% 신뢰구간
- (원하면) **ECFP + MLP 쌍 vs ECFP + SVR**
- 예시 코드:

```python
import numpy as np, pandas as pd
from scipy.stats import wilcoxon
d = pd.read_csv('eval_pairs_predictions_leakfree.csv')
ens = lambda name: d[[f'{name}_s{s}' for s in range(3)]].mean(1) if name != 'svr' else d['svr']
rm = lambda e: float(np.sqrt(np.mean(np.square(e))))
c = d[d.is_cliff]
def per_target(name):
    p = ens(name)[c.index]
    return c.assign(e=(p - c.delta) ** 2).groupby('target').e.mean() ** 0.5
a, b = per_target('molebert_pair'), per_target('ecfp_mlp_pair')
print('Wilcoxon p =', wilcoxon(a, b).pvalue, '| Mole-BERT가 낮은 타깃', int((a < b).sum()), '/ 30')
# 군집 부트스트랩 (평가 분자 단위)
g = c.groupby(['target', 'test_mol']).indices; keys = list(g); rng = np.random.default_rng(0)
pa, pb, y = ens('molebert_pair').values, ens('ecfp_mlp_pair').values, d.delta.values
diffs = []
for _ in range(2000):
    idx = np.concatenate([g[keys[k]] for k in rng.integers(0, len(keys), len(keys))])
    idx = c.index.values[idx]
    diffs.append(rm(pa[idx] - y[idx]) - rm(pb[idx] - y[idx]))
print('cliff RMSE 차이 95% CI', np.percentile(diffs, [2.5, 97.5]))
```

**위 코드를 이 파일로 실제 돌린 결과 (Mole-BERT 쌍 vs ECFP + MLP 쌍, cliff):**
Wilcoxon p = 0.30, Mole-BERT가 낮은 타깃 18/30, 군집 부트스트랩 RMSE 차이 95% CI [−0.034, 0.017] → **유의한 차이 없음 (대등).**
원고에는 "같은 쌍 입력에서 그래프 표현(Mole-BERT)과 지문 표현(ECFP)의 cliff 성능은 유의한 차이가 없었다"로 쓴다.
